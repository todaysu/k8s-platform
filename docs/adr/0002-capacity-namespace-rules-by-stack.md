# ADR-0002：按技术栈统一管理容量 Namespace 分类

- 日期：2026-10-18
- 状态：已被 ADR-0004 取代（2026-10-19）

## 背景

业务 Namespace 在所有集群中一致，但 TCS、CMBK8S 和 OCP 的平台组件 Namespace 不同。单一全局组件列表会造成错误分类，按集群独立配置又会产生大量重复规则和口径不一致。

## 决策

业务 Namespace 使用全局规则；平台组件 Namespace 使用公共规则加 TCS/CMBK8S/OCP 技术栈规则。不支持单集群例外。未匹配 Namespace 作为未分类容量单独扣减和展示。

## 后果

- 同技术栈的集群容量口径一致，新集群自动继承规则。
- 技术栈组件差异得到保留，避免将 OCP 系统组件误算为业务。
- 不能对单套集群建立例外；如出现真实需求，应先纠正技术栈或统一平台组件部署口径。
- 规则变更需要版本化，否则无法解释历史基线所使用的分类。
