# Namespace 分类视图

参考 PatternFly Tabs：https://www.patternfly.org/components/tabs/design-guidelines/ 。在原有容量分类弹窗中使用两个次级页签，不新增页面。

默认“待分类”仅显示尚未保存分类的 Namespace，隐藏已分类表格行和业务标签汇总；“已分类 · 修改”显示已分类项并允许调整归属或改回未分类。技术栈筛选同时作用于两个视图。行按加载时的已保存规则归组，修改后留在当前视图，避免选项变化导致行消失。切换视图保留所有未保存选择，保存沿用完整规则版本接口，并保留未显示规则。重新打开默认回到待分类。

测试覆盖默认隐藏、修改已分类项、跨页签保留草稿、保存时保留隐藏规则、改回未分类、技术栈空结果及重新打开时重置视图。
