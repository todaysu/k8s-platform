# FTC 集群运维平台品牌设计基线

## 1. 名称

- 正式名称：**FTC 集群运维平台**，用于浏览器标题、交付文档和正式汇报。
- 界面主标识：**FTC**，下方配“集群运维平台”，用于顶部导航与登录页，降低长名称占用的横向空间。
- 内部工程名：首版继续保留 `kubescope`，包括 Namespace、Deployment、数据库名和代码目录，避免一次 UI 品牌调整引发部署迁移。

## 2. 标识含义

标识为原创的“中心节点连接三个集群”图形：中心代表统一运维控制面，三个外部节点代表 G01、OCP 等多个资源池，也表达跨集群聚合、巡检与稳定性管理。它不是招商银行官方商标，也不临摹官方图形。

## 3. 视觉规则

- 品牌标识使用稳重的深红色 `#b3132b`，建立面向招商银行交付的识别感。
- 链接、筛选、主操作继续使用产品蓝色；危险、警告、健康继续使用红、黄、绿状态色。
- 顶部标识由“图形 + FTC + 集群运维平台”组成；空间不足时优先保留图形和 FTC。
- 正式上线前如获得招商银行标准 VI、字体和商标使用授权，只替换品牌组件与颜色令牌，不修改业务页面。

## 4. 应用范围

首版统一应用于全局 Masthead、登录页、浏览器标题和 favicon。部署资源名与 API 契约不随产品改名变化。

全局导航遵循单一控制器原则：桌面端由侧栏与内容区分隔线上的按钮切换完整栏和图标栏；小屏幕由 Masthead 菜单按钮开关覆盖式导航。两个按钮不在同一断点同时出现，避免侧栏状态冲突和按钮错位。
