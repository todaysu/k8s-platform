# 集群技术栈标签设计

## 决策

每个纳管集群增加一个平台侧技术栈标签，固定值为 `TCS`、`CMBK8S`、`OCP`。

- 新集群纳管时必须人工选择。
- 不向 Kubernetes 集群写入 Label，也不依赖集群组件名称自动判断。
- 集群列表、集群详情和跨集群资源搜索结果展示该标签。
- 集群列表支持按技术栈筛选。
- 旧数据库自动增加字段，既有集群标记为“未标记”，不影响连接凭据和健康采集。

## 取舍

本设计参考 ACM 使用 Cluster Label 分类和筛选集群的方式，但第一版不建设任意键值标签系统。固定枚举足以覆盖当前三种公司技术栈，录入和筛选更适合新手，后续确有机房、地域或用途等多维分类需求时再扩展通用标签。
