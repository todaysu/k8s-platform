# 审计日志可选导出与多文件分析设计

## 目标

将按时间导出从主分析页面移入按需打开的“生成导出命令”对话框，避免低频操作占用页面主线。支持一次导入 1–5 个同集群审计文件，统一分析轮转日志或多控制节点导出结果。

## 交互与过滤

- 导入区保留为页面主入口，新增“生成导出命令”次要操作。
- 导出对话框中的时间范围为可选开关，未开启时不对时间做限制。
- 可选精确过滤：Namespace、资源类型、Source IP、操作人、动作、结果。
- 资源名称采用“包含”匹配，同时适用完整 Deployment 名和带随机后缀的 Pod 名。
- 命令只在用户所在控制节点执行，平台不远程执行命令，不上传未经用户确认的日志。

## 多文件规则

- 一次选择 1–5 个文件，每个文件最大 20 MiB，总量最大 100 MiB。
- 文件必须属于同一集群；来源集群仍由用户显式标记。
- 文件按选择顺序拼接后交给 Web Worker。解析器按 `auditID` 合并 `RequestReceived`/`ResponseComplete` 等阶段，重叠文件不会生成重复请求。
- 超过文件数或单文件大小限制时拒绝整批导入，避免只分析部分文件却让用户误以为数据完整。

## 验收

1. 未打开对话框时，主页面不显示导出表单和命令。
2. 任一过滤字段都可单独使用，命令使用 shell 变量与 jq `--arg` 传值。
3. 同时导入两个含有同一 `auditID` 不同阶段的文件，页面只显示一条合并请求。
4. 选择超过 5 个文件或任一文件超过 20 MiB 时显示明确错误。
