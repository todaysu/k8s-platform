# 容量资源池边界设计

## 资源池定义

容量资源池的唯一边界为：

```text
环境 + 集群类型
```

示例：

- `STP / G01`：包含该环境下所有 TCS、CMBK8S 集群。
- `STP / OCP`：包含该环境下所有 OCP 集群。
- UAT、ST 等环境分别建立自己的 G01 与 OCP 池，禁止跨环境汇总。

## 技术栈定位

技术栈不是资源池边界，而是池内构成属性：

- G01 池可显示 `TCS n 套`、`CMBK8S n 套`。
- OCP 池通常只显示 `OCP n 套`。
- 单集群容量表继续显示每套集群的具体技术栈。
- 池级容量结论必须包含池内全部技术栈，禁止通过技术栈筛选生成不完整的“半个池”。

## 一致性

首页容量摘要和资源池容量详情使用相同的聚合键，确保资源池数量、最低余量和关注池数量口径一致。
