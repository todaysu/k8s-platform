# FTC v1 发布与运行报告演示设计

## 目标

- 将当前已完成功能统一发布为 `v1.0.0`。
- 生成 AMD64 和 ARM64 两个可离线导入的 Docker 镜像包。
- 创建三节点 Kind 环境，在本地验证安装向导、MySQL 连接和平台运行。
- 使用不污染真实数据库的方式，生成高数据量运行报告演示页。

## 发布方式

正常生产构建仍使用多阶段 `Dockerfile`。离线打包脚本在本机交叉编译静态 Go 二进制、构建前端，并下载经 SHA-256 验证的官方 kubectl，最后组装为 `scratch` 运行镜像。这条路径不依赖 Docker Hub 基础镜像站，适合当前开发机镜像加速站失效的情况。

## 演示报告

`cmd/reportdemo` 构造一个可重复的演示数据集，包含 12 套集群、217 次 Warning、7 类原因、5 个资源池和安全扫描信号。生成器直接调用正式 `reports.RenderHTML`，因此页面样式与实际报告一致，但不读写正式数据库。

分析重点为：先判断周期环比变化，再定位重复原因和热点集群，结合容量及安全信号给出有先后顺序的处置建议。
