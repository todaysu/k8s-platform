# 集群 kubectl 管理终端与界面外框

参考 Headlamp 的轻量浅色界面与集群操作模型：https://headlamp.dev/docs/latest/ 和 https://headlamp.dev/docs/latest/development/api/lib/apptheme/interfaces/apptheme/ 。

集群详情新增终端 Tab，绑定 URL cluster ID 和数据库已纳管凭据，管理员可执行 kubectl 管理命令，支持参数引号解析、命令历史、输出、退出码、停止与 YAML 标准输入。后端不经 Shell 启动 kubectl，使用 0700 临时目录和 0600 独立 kubeconfig；清空继承环境及默认 kubeconfig，执行后删除目录。禁止切换集群或凭据的参数、插件、读取本机文件的参数与文件型输出模板；-f 仅接受 - 和显式 YAML 输入。命令 60 秒上限、全局 4 并发、输出 1MiB 上限。不提供交互式 exec/edit/本机 Shell 或管道，Pod 交互终端沿用已有功能。POST API 由现有认证模块限制为管理员。

界面：顶部搜索相对整个窗口居中；账号、角色及账号菜单移到左下角，菜单向上展开。侧栏宽度 224px，收起 72px；移除内容框左右的额外嵌入间距，保留共享内容留白。浅灰蓝背景、白色顶部、浅蓝选中项，按钮采用较小圆角。修复导航单个 span 子元素被组件克隆造成不可聚焦的问题，保留图标和可访问链接。

验证：后端全量测试、前端 46 项测试、构建和 lint；通过已纳管 test01 凭据实际执行 kubectl get nodes，退出码 0，控制节点 Ready。页面隔离示例数据验证输出交互，测量搜索中心与窗口中心均为 640px，侧栏宽 224px。示例文件验证后删除。

## 终端全屏与菜单收起

终端命令输入移到黑色区域内部，Enter 执行，方向键选择历史命令，Ctrl+C 取消、Ctrl+L 清屏。全屏使用顶层 Portal，保持命令、历史和输出；锁定背景滚动、约束键盘焦点，Esc 或退出按钮恢复普通视图。后端仍使用原有按需执行器，不引入常驻 Shell / PTY，完整交互式 kubectl exec -it、edit 与持续流式输出仍不在此执行器范围。

侧栏移除独立平台权限项，管理员菜单中的平台角色权限进入现有管理页面。管理员菜单点击外部、Esc 或选中动作后关闭；搜索弹窗点击外部空白和 Esc 关闭，内部输入与结果操作不误关；关闭时清空旧查询/加载状态。事件更多筛选也支持外部点击关闭。

验证：49 项前端测试、构建、lint 通过；浏览器验证终端内部 Enter、全屏保留输出、Esc 恢复、管理员菜单和搜索内外点击行为。验证使用隔离示例数据，预览文件已删除。

## 持续 TTY 会话（2026-10-19）

复用 Pod 终端的 xterm + WebSocket 交互，集群终端使用同源、仅管理员可用的 `/kubectl/tty`。连接保持期间可以连续执行命令；运行时 stdin、ANSI 输出和窗口尺寸直接连接到服务端 PTY。支持 `kubectl exec -it POD -n NS -- sh`、`logs -f`、`get -w`、Ctrl+C 和容器中的交互程序，不再使用逐条 POST 的 60 秒超时。

全屏采用同一 DOM/组件，切换不重建连接。主动断开、离开页面、网络断开会取消执行，回收进程组和临时凭据；重新连接创建新会话，不恢复网络断开前的进程。保留四个并发命令限制。提示符只解析 kubectl 参数，不提供平台宿主机 shell、管道、凭据覆盖、本地文件读取或插件；容器 exec 的 `--` 后参数只交给远程容器。

验证：Go 全套测试；WebSocket 流式输出与取消测试；PTY 输入/输出测试；参数边界测试；50 项前端测试、构建和 lint。真实 test01 验证 get nodes、myapp 的 watch 取消，以及 myapp-standalone 的 exec -it sh 输入并退出。浏览器用独立模拟连接预览检查全屏与输出保留，预览文件及临时真实集群测试已删除。截图：data/kind-test/kubectl-tty-session.png。

## 终端 UI 收紧（2026-10-19）

将两层白色标题/操作区域合为一条深色工具栏：左侧为终端名称、集群与连接状态，右侧为清屏、重新连接、断开与全屏。操作按钮缩为 30px 高，取消大块危险色按钮；输出区域与工具栏连续连接，底部保留简短键盘操作提示。移动端允许工具栏换行，全屏仍保留同一 TTY 实例。删除不再使用的旧命令输入框样式。

前端构建、50 项测试及 lint 通过。独立模拟连接页面完成视觉检查，截图 data/kind-test/kubectl-tty-redesign.png；临时预览文件已删除。
