# FTC 集群运维平台 v1.1.0 离线交付说明

## 交付内容

- `images/ftc-platform-v1.1.0-amd64.tar`：AMD64 平台镜像。
- `images/ftc-platform-v1.1.0-arm64.tar`：ARM64 平台镜像。
- `images/kube-bench-v0.16.0-amd64.tar`：AMD64 安全扫描依赖镜像。
- `images/kube-bench-v0.16.0-arm64.tar`：ARM64 安全扫描依赖镜像。
- `manifests/install.yaml`：AMD64 单清单安装入口。
- `manifests/install-bootstrap.yaml`：需替换镜像地址的初始化清单。
- `manifests/platform-api.yaml`、`platform-collector.yaml`、`platform-worker.yaml`：60+ 集群角色拆分参考。
- `scripts/deploy-platform.sh`：普通 Kubernetes 自动识别 CPU 架构、渲染临时清单并部署的平台入口。
- `docs/`：安装、升级、架构、页面、使用、日常排障、平台参数、MySQL 资源配置与审核文档。
- `SHA256SUMS`：所有镜像归档的 SHA-256。

MySQL 是生产必需的外部依赖，不在交付包内携带 MySQL 镜像或 PVC。监控套件为可选集成，清单在源码仓库 `deploy/monitoring` 中，不归入必需镜像。

平台镜像导入所有目标节点后，推荐直接运行：

```bash
./scripts/deploy-platform.sh
```

脚本不会处理 kind，也不会替用户导入节点镜像或部署 MySQL。正式应用清单前，脚本会交互确认镜像已导入，以及 MySQL 8.0/8.4 已部署且平台 Pod 网络可达；任一项未确认都会停止。部署成功后必须使用 `https://<可达节点IP>:30080` 访问初始化页面，不使用 `127.0.0.1`。

## 校验与导入

```bash
shasum -a 256 -c SHA256SUMS
docker load -i images/ftc-platform-v1.1.0-amd64.tar
docker load -i images/kube-bench-v0.16.0-amd64.tar
```

导入内网仓库后，修改安装清单中的平台镜像，并在平台配置中设置对应架构的 `SECURITY_KUBE_BENCH_IMAGE_AMD64` 或 `SECURITY_KUBE_BENCH_IMAGE_ARM64`。

## 安装前检查

1. 已准备 MySQL 8.4 及独立数据库和最小权限账号。
2. 已准备平台域名和匹配 SAN 的 TLS 证书。
3. 已生成 32 字节凭据加密密钥，并纳入密钥备份。
4. 已核对平台到全部目标 Kubernetes API、Prometheus 和 Alertmanager 的网络连通性。
5. 60+ 集群部署使用 API 2、Collector 2、Worker 1 的起始规模，并完成容量验收后再标记为生产。

## 回滚

回滚前先备份 MySQL。平台镜像可回退到上一版，但不得在不执行专用迁移的情况下更改已持久化的 `COLLECTION_SHARDS`。详细步骤见 `docs/upgrade.md`。
